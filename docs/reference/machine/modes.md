A numerical flute mode is defined as:

$$
m(\psi, \theta, \zeta) = \sum_{m,n} \alpha(\psi, \theta, \zeta)\cos\big(m\theta-n\zeta+\phi(\psi, \theta, \zeta)\big)
$$
